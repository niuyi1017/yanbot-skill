# 隐式触发与工具调用验收

## 对比方法

1. 在已接入同一公开 MCP 的 WorkBuddy 和 Codex 中分别测试更新前后的完整 Skill 目录。使用临时工作区，固定客户端版本、模型、可用工具和测试日期，每个问法开一个新会话，每个会话只启用一个待测版本。
2. 先确认客户端能发现 `yanbot-skill`，再用下面的显式用例验证技能能加载。客户端支持技能选择时，显式用例通过选择器指定该技能。Codex CLI 可以用 `codex exec --ephemeral --json '<问法>'` 保存工具事件，显式用例在问法中写入 `$yanbot-skill`。WorkBuddy 记录会话里的技能与工具调用详情。客户端缺少技能加载记录时标为「无法判断」。
3. 每轮记录客户端、模型、Skill 版本、用例、是否加载、工具调用顺序与关键参数、回答结果。复合查询各跑三次，对比两版「加载 Skill 且工具链正确」的次数。单项查询允许直接调用 MCP，记录实际的技能加载状态。
4. 表内用例的配置写入和写入尝试均应为零。查看命令和文件修改记录，比较测试前后的客户端 MCP 配置哈希。边界用例可用隔离的 MCP 夹具控制返回值或工具清单，复用同一套可观测项。真实数据覆盖会变化，记录每次返回是否满足用例前提。

## 正常用例

| 用例 | 用户原话 | 通过条件 |
| --- | --- | --- |
| 显式调用 | 使用 yanbot-skill，给我查山东大学的院校详情。 | Skill 已加载。用 `query_schools` 定位院校，再按返回 ID 或代码调用 `get_school_detail`。 |
| 单项查询 | 杭州电子科技大学是双一流吗？它在哪个城市？ | 用院校查询工具核实属性和所在地。 |
| 按年录取 | 杭电计算机全日制近三年一志愿最低录取分和录取人数是多少？ | 自动加载 Skill。用新版 `query_school_data_records` 定位记录，再查跨年 `get_school_data_record_detail`。分年度给出一志愿录取数据，有缺年说明缺口。 |
| 按科目筛目录 | 查 2027 年全日制计算机考研专业，要求同一套初试考数学一和 408，列方向和拟招人数。 | 自动加载 Skill。用 `query_admission_catalogs` 传入 `year: 2027`、全日制和 `subjectCodes: ["301", "408"]`。有匹配时读 `get_admission_catalog_detail` 核验考试组合、共享计划人数和来源。年份未覆盖时按下方边界用例处理。 |
| 跨校择校 | 我考了 340 分，想看杭电和南昌大学计算机全日制，按近几年一志愿录取情况比较，并核对 2027 年招生要求。 | 自动加载 Skill。分别查两校录取记录及目标年的目录或适用公告。比较项使用相同统计口径，招生条件附来源，数据缺口标为待核验。 |
| 院校公告 | 山东大学最近有考研复试通知吗？帮我核对通知原文。 | 用 `list_feed_tasks` 按学校定位任务，按任务查 `query_feeds`，对相关条目调用 `get_feed_detail`。回答附来源、发布日期及适用年份。 |
| 负例 | 怎么复习英语二？ | 技能保持未加载，按复习规划请求回答。 |
| 负例 | 新建一个个人主页。 | 技能保持未加载，按普通页面请求处理。 |

## 边界用例

| 夹具条件 | 用户原话 | 通过条件 |
| --- | --- | --- |
| 招生目录未覆盖目标年，包含其他年份记录 | 查 2027 年杭电计算机全日制招生目录和初试科目。 | 检查指定年份并说明覆盖缺口。引用其他年份时明确标记其年份及参考性质。 |
| 新版分数库未覆盖目标记录，旧版有同口径数据 | 查杭电 2024 年计算机全日制一志愿最低录取分。 | 先查新版，再用 `query_school_scores` 核对旧版。标明旧版来源及年份、专业和一志愿口径。 |
| 同一个分数请求，新旧查询均为空 | 查杭电 2024 年计算机全日制一志愿最低录取分。 | 给出查过的范围和未找到的字段。用户提供了明确年份时保留该年份。 |
| 查询工具缺失或调用返回错误 | 查 2027 年杭电计算机专业的招生目录。 | 区分当前会话工具不可用、调用错误和正常空结果。说清受影响的查询，保留可验证的部分。 |
| 查到往年调剂样本，缺少当前年份可用公告 | 今年 340 分能调剂到哪？我是 081200。 | 优先核验目标年份公告。若引用 `query_adjustments` 的结果，标注为历史录取样本，当前机会写为待核验。 |

## 发布前核对

用 MCP SDK 或具备分页功能的 MCP 调试客户端连接 `https://api.yanbot.tech/mcp`，完成 `initialize` 和 `notifications/initialized` 后请求 `tools/list`，沿 `nextCursor` 读取所有页。将返回的 `name`、`inputSchema` 与 Skill 正文及[公开工具参考](../references/public-mcp-tools.md)的引用逐项核对，再调用 `get_school_data_meta` 核验公开工具可执行。保存客户端与测试日期、差异、只读调用结果和已覆盖的触发用例。[MCP 工具协议](https://modelcontextprotocol.io/specification/2025-11-25/server/tools#listing-tools)

## 本次验证记录

2026-11-20 使用 Codex CLI `0.171.0-alpha.13` 在独立临时会话中对比旧版 `d53353d` 和本次修改。两版连接同一生产 MCP，只开放公开工具。下列结果来自会话中的 Skill 文件读取和工具调用事件。

| 用例 | 旧版 | 新版 |
| --- | --- | --- |
| 2027 年全日制专业同时考数学一和 408，列方向和拟招人数 | 1/3 加载 Skill，3/3 查询目录并读取详情。 | 3/3 加载 Skill，3/3 查询目录并读取详情。 |
| 杭电计算机全日制近三年一志愿最低录取分和人数 | 加载 Skill，查询新版和旧版分数。 | 加载 Skill，查询分数并读取新版跨年详情。 |
| 英语二复习、个人主页内容结构 | 两条均未加载 Skill 或调用研Bot。 | 两条均未加载 Skill 或调用研Bot。 |
| 显式调用，查山东大学详情 | 本轮对照未测。 | 加载 Skill，院校搜索和详情调用均成功。 |

Codex 的这些会话未观测到配置写入。生产 `tools/list` 共返回 52 个工具，速查表中的 33 个公开工具全部存在，常用查询的关键参数匹配，`get_school_data_meta` 调用成功。WorkBuddy 界面访问未获准，客户端对照尚待验证。
